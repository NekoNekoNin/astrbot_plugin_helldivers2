# 绝地潜兵2资料与战况

查阅武器与机制、核对官方简中译名，结合银河战争实况、历史和补给线分析支援目标。

版本：`1.0.5` · 许可：[MIT](LICENSE)

作者：**NekoNekoNin**。

## 能做什么

- 检索同一 Helldivers Wiki 的中文与英文语言版本，保留章节、详细表格和修订链接。
- 通过本地游戏同字符串 ID 核对已收录的官方简中名称，缺项时继续按原名或型号查阅。
- 读取官方 Steam 更新、银河战争实况与历史，区分解放、防御和区域战役进度。

## 支持平台与标签

支持 QQ / OneBot v11（`aiocqhttp`，如 NapCat）与 AstrBot 内置 WebChat（`webchat`）。市场平台字段表示消息适配器；当前声明按已接入和验收范围填写，其他平台尚未验收。

标签：绝地潜兵2、游戏、Wiki、银河战争、数据查询。

## 安装

在 AstrBot 的插件管理上传本插件发布 ZIP，或使用[本仓库地址](https://github.com/NekoNekoNin/astrbot_plugin_helldivers2)安装。内部插件名保持 `astrbot_plugin_helldivers2`，升级时沿用已有配置。元数据已绑定本仓库，更新时请核对版本与更新记录。

资料查询不需要 API Key，也不要求安装游戏。插件随附的是部分名称索引；只有更新本地译名索引时才需要自己的游戏导出。

## 设置

入口：**AstrBot → 插件 → 绝地潜兵2资料与战况 → 配置**。常用选项直接显示，适用时提供中文下拉标签、数值滑块、条件显示与高级折叠。完整选项见 [配置说明](docs/CONFIGURATION.md)。

## 聊天示例

- “查询武器爆裂铳。”
- “比较 AR-23 和 AR-23P 的参数与适用场景。”
- “结合当前银河战争和历史，推荐支援星球并说明依据。”

## 使用边界

中文与英文是同一 Wiki 的语言版本，不算两份独立证据。本地译名索引不是全集，缺项不表示名字不存在。星球曲线最多近 7 天，事件及主要指令最多近 48 小时，以实际覆盖为准；不凭一个快照推算精确完成时间。

## 本地译名索引

当前资源记录 Steam 构建 26088801 的部分同 ID 英文/简中名称。保留构建号、字符串 ID 与资源哈希；原始游戏导出不进入仓库。更新方法见 [译名导入说明](docs/LOCALIZATION.md)。

搭配“资料卡与表格图”插件，可把已查阅数据整理成图片。
